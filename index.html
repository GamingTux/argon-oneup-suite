⚡ Argon ONE UP Debian / APT Repository

Official Hardware driver and power management suite repository for the Argon ONE UP Raspberry Pi CM5 laptop.

📦 Automated Installation via Essentials

Installing argon-oneup-essentials automatically configures this repository and its GPG keyring.

🔧 Manual Repository Setup

To manually add this repository to any Debian / Raspberry Pi OS / Ubuntu system:

# 1. Download and install the GPG signing key
sudo mkdir -p /usr/share/keyrings
curl -fsSL https://gamingtux.github.io/argon-oneup-suite/argon-oneup-archive-keyring.gpg | sudo tee /usr/share/keyrings/argon-oneup-archive-keyring.gpg > /dev/null

# 2. Add the repository sources list
sudo tee /etc/apt/sources.list.d/argon-oneup.sources << 'EOF'
Types: deb
URIs: https://gamingtux.github.io/argon-oneup-suite/
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/argon-oneup-archive-keyring.gpg
EOF

# 3. Update APT and install the suite
sudo apt update
sudo apt install argon-oneup-suite
